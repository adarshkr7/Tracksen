Two things worth knowing before you quote anything out of these:

**Some of it is dated.** `PLAN.md` was written to a 10 September deadline and has not been
revised since; `STATUS.md` and `AUDIT.md` carry the date of the pass that produced them.
Where a number here disagrees with the top-level README, the README is the one that was
re-run.

**None of this is an Indian Railways product.** Every figure comes from synthetic
operational data over a real network topology, except where a document names a published
source — and `RESEARCH.md` names its sources for exactly that reason.
